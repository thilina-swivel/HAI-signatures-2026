How to install it

  1. Press Copy signature above.
  2. In Outlook, open Settings (the gear icon) → Mail → Compose and reply.
  3. Under Email signature, select + New signature and name it humaniseAI.
  4. Click inside the editing box and paste with Ctrl + V (⌘ + V on Mac).
  5. Set it as the default for new messages and replies/forwards, then Save.
